## 📦 Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Rima-Tasneem/EventSpahare-Fontend.git
   ```

2. Navigate to the project folder:

   ```bash
   cd EventSpahare-Fontend
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```
